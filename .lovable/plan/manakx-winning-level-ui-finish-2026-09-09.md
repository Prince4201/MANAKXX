# MANAKX Winning-Level UI Finish

## Goal
Turn the existing working prototype into a polished SIH judging experience without changing its deterministic local engine or synthetic-data safeguards.

## Visual direction
- Deep civic navy, warm white, saffron and emerald accents
- Sora display typography with Manrope body text
- Strong asymmetric layouts, crisp borders, compact radii and restrained motion
- Real Indian infrastructure imagery rather than generic AI decoration

## Build
1. Recompose the opening screen around the real MANAKX value proposition, demo actions, generated infrastructure image and a credible live analysis panel.
2. Improve the workflow, proof, capabilities and final call-to-action sections with clearer hierarchy and richer product evidence.
3. Refine the shared application shell, navigation, page headers, cards and status surfaces so the signed-in product matches the opening screen.
4. Preserve every existing route and interaction; improve mobile layouts and reduced-motion behavior.
5. Verify the opening screen and core demo journey in the browser at desktop and mobile sizes.

## Technical details
- Keep TanStack Start routing and existing localStorage data engine unchanged.
- Use semantic design tokens in `src/styles.css` and existing shared UI controls.
- Import the new hero image from project assets with fixed dimensions and meaningful alt text.
- Keep all synthetic-data and non-official guidance disclaimers visible.
